# Player-Stats-System

Sistema de análise de desempenho para jogadores de vôlei, focado em **scout simples, rápido e justo**.

🔗 Acesse: [Aqui]()

---

## 📊 Sobre o projeto

A Planilha VBL foi criada para facilitar a avaliação de jogadores durante partidas ou treinos, trazendo:

- Controle de **pontos feitos (scored)**
- Pontos sofridos (**scored on**)
- Erros ofensivos (**mistake OF**)
- Erros defensivos (**mistake DEF**)
- Cálculo automático de **rating (0 a 10)**
- Sistema de **eficiência e consistência**
- Destaque de **MVP e Worst player**
- Suporte a **até 3 sets + resultado final**

---

## 🎯 Objetivo

Criar uma ferramenta justa onde:

- Fazer pontos é valorizado 📈  
- Erros impactam, mas não destroem o jogador ⚖️  
- Jogadores não são punidos por funções (ex: setter)  

---

## 🧠 Como funciona o rating

O rating vai de **0 a 10** e considera:

- Pontos feitos (principal peso)
- Pontos sofridos
- Erros (OF + DEF)
- Eficiência geral

👉 O sistema foi ajustado para:
- Evitar ratings muito baixos com facilidade
- Valorizar impacto positivo no jogo
- Ser mais motivador para os jogadores

---

## 🧩 Funções por posição

- **Ponteiro / Oposto / Líbero / DS Spiker**
  - Influenciam com pontos, erros e defesa

- **DS Tsk / Setter**
  - Não são obrigados a pontuar
  - Pontuar = bônus
  - Erros impactam levemente

## 📊 About the project

The VBL Spreadsheet was created to facilitate player evaluation during matches or training, providing:

- Control of **points scored**
- Points conceded (**scored on**)
- Offensive errors (**mistake OF**)
- Defensive errors (**mistake DEF**)
- Automatic calculation of **rating (0 to 10)**
- **Efficiency and consistency** system
- **MVP and Worst player** highlighting
- Support for **up to 3 sets + final result**

---

## 🎯 Objective

To create a fair tool where:

- Scoring points is valued 📈
- Errors impact, but don't destroy the player ⚖️
- Players are not penalized for roles (e.g., setter) ---

## 🧠 How the rating works

The rating ranges from **0 to 10** and considers:

- Points scored (main weight)
- Points conceded
- Errors (OF + DEF)
- Overall efficiency

👉 The system has been adjusted to:

- Avoid very low ratings easily
- Value positive impact on the game
- Be more motivating for players

--

## 🧩 Roles by position

- **Outside Hitter / Opposite / Libero / DS Spiker**

- Influence with points, errors, and defense

- **DS Tsk / Setter**

- Not required to score

- Scoring = bonus

- Errors have a slight impact
